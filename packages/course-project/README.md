# 课程项目交换格式 v1

课件与通用导入器共享此契约，两个应用可独立构建。原件附件、正文片段、阅读任务、个人笔记、关系、研究主张、修改日志分别保存。PDF 定位是从 1 开始的物理页序，印刷页码为独立字符串；Word 使用段落定位。

`project.json` 可单独交换记录。完整 `.zip` 还包含 `attachments/<附件编号>`、指纹和缺失附件清单。导入先校验，随后在一次 IndexedDB 事务中保存，失败不覆盖现有项目。重复文件按指纹提示，重复编号保留原有记录；不会把文件相同解释成版本相同。模型凭据不属于项目。

跨应用通过明确打开的导入器窗口交换 `PKU_IMPORT_READY` / `PKU_PROJECT` 消息，接收者必须检查窗口身份、精确 origin 和项目版本。应用也支持下载与上传备份，部署在不同站点时不依赖共享浏览器存储。

内部编号使用字母、数字、连字符与下划线，便于跨应用及Markdown文件保留。恢复前检查笔记、链接与问题依据的引用，不能把断裂关系写入当前项目。
