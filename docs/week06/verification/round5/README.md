## 受测对象与边界

- 教师 Mac 上的 Google Chrome **155.0.8059.85**；UA-CH 报告 macOS **26.6.2 / arm**。使用新的隔离浏览器配置，不改教师日常配置或模型缓存。
- `browser-round2.json` 是沿用主脚本的报告文件名，内容是**本轮**运行：15 组交互检查，26 页×桌面／窄屏，加独立课前检查页，共54个页面状态。

- 本轮没有模型推理或真实API请求。D01/D02/D03/D06/D08/D11里的数据是已有的公开材料实跑回放；主交互检查会注入明确的合成记录，不能用其分数证明模型效果。
- 不读取教师原件做截图。v5检查阻断教师原件图像路径、外部请求和POST；课前检查仅查询本机材料清单。未替教师申请持久存储。
