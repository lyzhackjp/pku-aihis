## 第一组：把识读拆成几种判断

### 计算机视觉 | computer vision

页面：D02

原文与别称：computer vision；常简称 CV

出现位置：讲义第一节 1.1

它解决什么问题：让机器从图像中得出判断：图上有什么、在哪里、是什么。

文字识别常被当作一个整体："放进扫描件，得到文字"。计算机视觉提供了把它拆开的词汇：识读一页文书，其实是一连串不同的视觉判断——先找到哪里有字，再判定每一处是什么字。用这套词汇描述错误，就能说清错误出在哪一步，而不只是说"识别不准"。

容易混淆：计算机视觉是一个研究领域，文字识别只是它的一项应用；人脸识别、医学影像分析也属于它。

对历史研究意味着什么：能把"机器读错了"拆成"没找到""找错了范围""认错了字""排错了顺序"，才知道该换工具、改参数还是人工补救。

### 图像分类 | image classification

页面：D02

原文与别称：image classification

出现位置：讲义第一节 1.1

它解决什么问题：回答"这是什么"：给一张图，从事先定好的类别中选一个。

识读中最直接的分类是认字：给出一个字的切片，从字表中选出它是哪个字。判断一块区域是正文、页码还是插图，也是分类。把《史德》中的"盡"认成"姦"，就是一次分类错误。

容易混淆：分类只能在已有的类别中选；字表里没有的字，模型无论如何也认不出来，只会选一个最像的。

对历史研究意味着什么：生僻字、异体字是否在字表中，决定了模型有没有可能读对它。

### 目标定位 | object localization

页面：D02

原文与别称：object localization

出现位置：讲义第一节 1.1

它解决什么问题：在分类之外回答"它在哪里"。

定位的结果通常用边界框（见下条）表示。识读工具给每一行文字的那组坐标，就是定位的结果；有了它，才能从识读文字回到原图上的位置。

容易混淆：定位一般针对已知数量的对象；对象数量与种类都不确定时，叫目标检测。

对历史研究意味着什么：没有位置信息的识读文本，无法逐行回到原图核对。

### 边界框 | bounding box

页面：D02

原文与别称：bounding box；也称包围盒、检测框

出现位置：讲义第一节 1.1

它解决什么问题：用最简单的方式记录一个对象在图上的位置。

一个边界框通常是四个数：左上角的横坐标与纵坐标、宽与高。NDL 系识读工具对《史德》第 3 行的记录是 X=689、Y=132、宽 38、高 1116（单位为像素），这一行字就落在这个矩形里。

课堂上你会看到：识读结果可视化图上一个个彩色的矩形框。

容易混淆：矩形框框不准弯曲的手写行，这时要用基线与多边形（见第二组）。

对历史研究意味着什么：保存识读结果时要连同边界框一起保存，它是"原始识读"这一层记录的一部分。

### 目标检测 | object detection

页面：D02

原文与别称：object detection

出现位置：讲义第一节 1.1

它解决什么问题：图上有多少个对象、各是什么、各在哪里，事先都不知道，要一并找出来。

在一页文书上找出所有的文本行、标题、页码与插图，就是一次检测：每找到一个对象，都要给出它的边界框和类别。《史德》一页上，书口与页码被检测出来了，类别却被判成了"本文"。

容易混淆：检测＝找出所有对象＋各自定位＋各自分类；文字识别则是在检测出的每一行里再逐字分类。

对历史研究意味着什么：检测漏掉的行，后面的识读根本不会处理；核对时要先看"行找全了没有"。

### 图像分割 | image segmentation

页面：D02

原文与别称：image segmentation；分为语义分割（semantic segmentation）与实例分割（instance segmentation）

出现位置：讲义第一节 1.1

它解决什么问题：比矩形框更精细地判断哪些像素属于哪个对象。

语义分割为每个像素标出类别（这是文字、那是背景）；实例分割还要区分是哪一个对象（这是第 3 行、那是第 4 行）。手写文书的行弯曲、交叠，Kraken 一类系统先用分割得到每个像素的类别，再从中提取每一行的基线和轮廓。

容易混淆：分割与检测的区别在精细程度：检测给矩形框，分割给像素级的轮廓。

对历史研究意味着什么：处理行款不齐、字间穿插的写本时，分割比矩形框更可靠。

## 第二组：看得见与排得对

### 版面分析 | layout analysis

页面：D03

原文与别称：layout analysis；也称版面识别、版面检测、文档版面理解

出现位置：讲义第一节 1.2

它解决什么问题：在识字之前，先把页面分成正文、标题、注释、页码、插图等区域并判明类别。

一页刻本上有正文、双行小注、书口、页码；一页日本近代书籍上有正文、振假名、柱、页码。版面分析决定了哪些区域进入正文。它能看见什么，取决于开发者事先定下的类别清单：清单上没有"书口"，书口就只能被归入别的类，比如被当成正文。

课堂上你会看到：识读结果上不同颜色的框，分别代表正文、标题、注音、页码等类别。

容易混淆：版面分析处理的是区域与类别，不读出文字；读字是后面文字识别的事。

对历史研究意味着什么：页码混进正文、注文混进正文，会一路传进检索与引用；校对识读结果时，先看版面。

### 文本检测 | text detection

页面：D03

原文与别称：text detection

出现位置：讲义第一节 1.2

它解决什么问题：在图上找出每一处文字，通常以文本行为单位给出边界框。

文本检测是目标检测在文字上的应用：只关心"哪里有字"，不关心是什么字。PP-OCRv6 的流水线第一步就是文本检测，结果是一组框，交给第二步的识读模型。

容易混淆：文本检测与版面分析常一起完成，但前者只找字，后者还要判断区域的类别。

对历史研究意味着什么：淡墨、残字、朱笔批注最容易被漏检。

### 文本行 | text line

页面：D03

原文与别称：text line

出现位置：讲义第一节 1.2

它解决什么问题：为识读模型提供一次处理的单位。

大多数识读模型一次读一行：检测先把页面切成一条条行，识读模型再逐行读出文字。竖排书籍中的一"行"是从上到下的一列。《史德》一页被检测为 16 个文本行，其中两行实际上是书口与页码。

容易混淆：识读意义上的"行"不一定等于原书的行：一行可能被拆成两段，双行小注可能被合成一行。

对历史研究意味着什么：识读结果中的行号是机器的编号，引用时仍要以原书的行款与页码为准。

### 基线 | baseline

页面：D04

原文与别称：baseline

出现位置：讲义第一节 1.2

它解决什么问题：为弯曲、倾斜的手写行提供比矩形框更准确的位置表示。

基线是一行文字底部那条看不见的线，字母"站"在它上面。Kraken、Transkribus 先画出每一行的基线，再围出包住这一行的多边形，然后把这一行"拉直"交给识读模型。讲义图 3 是 Kraken 官方文档中的流程图。

课堂上你会看到：手写页面上沿着每行文字底部画出的彩色折线，以及包住各行的不规则多边形。

容易混淆：基线是一条线，边界框是一个矩形；手写材料多用前者，印刷材料多用后者。

对历史研究意味着什么：行间夹写、改字的写本，基线画错会把两行文字混在一起。

### 阅读顺序 | reading order

页面：D02

原文与别称：reading order

出现位置：讲义第一节 1.1、1.3

它解决什么问题：把检测出的一组文本行排成可以连续阅读的先后顺序。

横排现代文档大体"从上到下、从左到右"；竖排书籍"从右到左"；多栏、双行小注、眉批、振假名则需要逐一决定。同一页的不同学术用途，可能要求不同的读序：做全文检索时可以把小注放在句后，做校勘时也许要单独列出。

容易混淆：阅读顺序不属于分类、定位、检测、分割四项任务中的任何一项，是在检测结果之上另外建立的先后关系。

对历史研究意味着什么：读序是录文者的编辑决定，应写进录文规范，不能默认交给机器。

### XY切分 | XY-cut

页面：D05

原文与别称：XY-cut；递归 XY 切分

出现位置：讲义第一节 1.3

它解决什么问题：用规则把页面上的各行排出读序。

做法是：在整页上找最宽的一条空白，沿它把页面一分为二；在每一半里继续找空白、继续切，直到每块只剩一行或一组整齐的行；最后按"竖排从右到左、横排从上到下"读出各块。NDLOCR-Lite 就用它排读序（讲义图 5）。

容易混淆：XY 切分是规则方法，不用训练；学习式的读序方法则从标注好读序的大量页面中学规则。

对历史研究意味着什么：版心规整的刻本与印刷物用它效果好；插在行间的小注、围在四周的批注，它表达不了。

### 交并比 | Intersection over Union

页面：D06

原文与别称：Intersection over Union；简称 IoU

出现位置：讲义第一节 1.3 末＊注

它解决什么问题：衡量机器画的框与人工画的框重合得好不好。

用两个框重叠部分的面积，除以两个框合起来覆盖的面积：完全重合为 1，毫不相交为 0。评测文本检测时，常规定交并比超过某个阈值（如 0.5）才算"找到了"这一行。

容易混淆：交并比衡量位置，字符错误率衡量文字；框画得准不等于字读得对，反之亦然。读序是否正确，两者都反映不了。

对历史研究意味着什么：看到工具报告的"检测准确率"时，要问它用的是什么阈值、在什么材料上算的。

## 第三组：读得准

### 字符集 | character set

页面：D07

原文与别称：character set；也称字表、词表（vocabulary）

出现位置：讲义第二节 2.1

它解决什么问题：规定识读模型能够输出哪些字符。

NDLOCR-Lite 的字表有 7141 个字符，"德""徳"都在其中。字表之外的字，模型只能从表内选一个最像的代替；所以生僻字、异体字、自造符号能否被读出，首先取决于字表。

容易混淆：字表里有某个字形，不等于模型会输出它（见"语言先验"）。

对历史研究意味着什么：处理有大量异体字或特殊符号的材料前，先查一查工具的字表。

### 序列预测 | sequence prediction

页面：D02

原文与别称：sequence prediction；也说序列识别

出现位置：讲义第一节 1.1、第二节 2.1

它解决什么问题：一次读出一整行字，而不是一个字一个字地分别判定。

认一个字是分类：从字表中选一个。读一整行，则要输出一串长短事先不知道的字，每一处的判断还和前后有关，这就是序列预测。今天的识读模型大多整行地读，连接时序分类（见下条）和带语言先验的解码器，都是把一串判断变成一个字符串的办法。

容易混淆：序列预测的基础仍是分类，只是每一处的分类连成一串，并互相影响；所以前后文会左右某一个字被读成什么。

对历史研究意味着什么：整行读不必先切字，适合连笔与粘连的写本；但一个字的读法会受上下文牵动，单看这一个字的图像说明不了它为什么被读成这样。

### 连接时序分类 | Connectionist Temporal Classification

页面：D07

原文与别称：Connectionist Temporal Classification；简称 CTC

出现位置：讲义第二节 2.1

它解决什么问题：让模型不必先把一行切成单字，也能读出整行文字。

模型把一行图像看成一串窄条，为每一条输出一组概率：字表里每个字一个，再加一个"空白"（此处无字）。CTC 规定了一个固定的映射：先合并相邻的重复判断，再删去空白，剩下的就是字符串。例如逐条判断"盡、盡、空白、其、其、空白、空白、理、理、空白"，合并重复后为"盡、空白、其、空白、理、空白"，删去空白得"盡其理"。许多条不同的逐条判断（"路径"）会映射到同一个字符串；一个字符串的概率，是所有这些路径的概率之和，每条路径的概率是各窄条所选项概率的连乘。训练时让正确字符串的概率尽量大，所以只需要"整行图像＋整行文字"，不必逐字标位置；读字时最简单的做法是每个窄条取概率最大的一项，再合并、删空白（"最佳路径解码"，讲义有伪代码与"盡其理"的演算）。

课堂上你会看到：D07 演示页上，PP-OCRv6 为一行《史德》算出的概率表：横向是窄条，纵向是候选字；逐步点亮每条的最大项，再合并、删空白。

容易混淆：CTC 本身不是一个完整的模型，而是接在卷积网络与循环网络之后的输出规则与训练目标；它假设各窄条的输出彼此独立，选字时不参考已经选出的字。最佳路径解码不保证找到概率最大的字符串。

对历史研究意味着什么：它让连笔、粘连的手写也能整行识读；但它本身不知道字与字之间的搭配。

### 语言先验 | language prior

页面：D08

原文与别称：language prior；也说"内部语言模型"

出现位置：讲义第二节 2.1

它解决什么问题：解释识读模型为什么会"读出"图像上没有的字形或字序。

许多识读模型在学认字的同时，也学会了"上一个字是这个，下一个字多半是那个"。这能帮它猜对看不清的字，但也会把不常见的写法拉向常见的写法：《史德》中原页的"德"被输出为日本通行的"徳"，"愚估""貿化"被读成"愚佑""質化"。

容易混淆：语言先验是模型从训练数据中学来的倾向，不是录文规范；它在每一处都可能作出不同的选择，同一页上"斷"有时输出为"断"，有时不变。

对历史研究意味着什么：生僻字、人名、时代用字、原书错字最容易被它"改"掉；核对时要特别留意。

### 置信度 | confidence

页面：D09

原文与别称：confidence；也称置信分数

出现位置：讲义第二节 2.2

它解决什么问题：报告模型对自己某一次判断有多大把握。

识读工具常为每行或每字给出一个 0 到 1 之间的数，但各工具算的东西不同。NDL 识读 XML 中的 CONF，是版面检测模型对"这个框是一个某类文本行"的把握，写出时字还没有读；PP-OCRv6 报告的分数来自识读本身，是一行中保留下来的每个字最大概率的平均。《史德》一页上，把"盡"读成"姦"的那一行 CONF 为 0.856，与完全读对的行相差无几；CONF 最低的两行，是页码与"卷三"。

容易混淆：置信度是模型的自我估计，不是正确率；同叫"置信度"，检测的分数与识读的分数是两回事；行级分数不能告诉你哪个字错了。

对历史研究意味着什么：可以用它找整行都有问题的地方，不能用它证明某行已经可靠。

### 校准 | calibration

页面：D09

原文与别称：calibration；校准良好（well-calibrated）

出现位置：讲义第二节 2.2

它解决什么问题：检验模型报告的把握与它实际的正确率是否相符。

一个校准良好的模型，报告 0.9 把握的那些判断，大约有九成是对的；报告 0.6 的，大约六成是对的。校准差的模型，可能在读错的地方同样报告很高的把握。《史德》一页上，读错"盡"字的那一行置信度为 0.856，与读对的行相差无几，就是一个例子。

容易混淆：这里的"校准"是机器学习术语，与校勘的"校"无关；也不同于扫描仪、相机的色彩校准。

对历史研究意味着什么：识读工具一般不保证在历史材料上校准良好；想按置信度安排校对，先用人工小样本看一看自己材料上的情况。

### 手写文本识别 | Handwritten Text Recognition

页面：D04

原文与别称：Handwritten Text Recognition；简称 HTR

出现位置：讲义第一节 1.2

它解决什么问题：识读手写的文书，而不只是印刷品。

手写的行弯曲、字形因人而异、连笔与改字常见，所以手写识别系统通常用基线与多边形表示行，并且要针对某一类书写训练模型。Kraken／eScriptorium 与 Transkribus 是目前历史学者最常用的两类手写识别系统。

容易混淆："OCR"一词常被泛用来指所有文字识别；严格说，OCR 起初指印刷字符识别，HTR 指手写识别。

对历史研究意味着什么：手写识别的效果高度依赖训练数据是否接近自己的材料；先用小样本试一试。

## 第四组：完成识读的三类模型

### 流水线 | pipeline

页面：D10

原文与别称：pipeline；本讲也称"分步骤识别"

出现位置：讲义第三节

它解决什么问题：把识读拆成检测、识读、排序等几步，每一步交给一个专门的模型。

PP-OCRv6 先用检测模型找出文本行，裁切后交给识读模型逐行读字；NDLOCR-Lite 再加上 XY 切分排读序。每一步都有中间输出，错误可以追到具体的一步。

容易混淆：流水线不等于"旧技术"；2026 年仍有新的流水线模型发布，在一些材料上胜过大模型。

对历史研究意味着什么：中间输出带坐标，最容易做到逐行回到原图、分步查错。

### 视觉语言模型 | Vision-Language Model

页面：D03

原文与别称：Vision-Language Model；简称 VLM

出现位置：讲义第一节 1.2、第三节

它解决什么问题：用一个同时理解图像与语言的模型直接从页面写出文本。

视觉编码器把页面图像切成小块编码，交给语言模型写出文字。专门为文档训练的视觉语言模型，如 dots.ocr，还能一并给出版面框、类别与读序。

容易混淆：本讲在广义上使用这个词：小型的多任务模型 Florence-2、专为文档训练的 dots.ocr、通用的多模态大语言模型（见下条），都是"图像编码器＋写文字的解码器"，区别在规模与是否专门为文档识读训练。

对历史研究意味着什么：它的错误常常"通顺而错误"：补写看不清的字、把原文改成规范写法；核对时要特别留意人名、地名与异体字。

### 词元 | token

页面：D10

原文与别称：token

出现位置：讲义第三节 3.1（Florence-2）

它解决什么问题：规定语言模型一次读入或写出的最小单位。

语言模型并不直接处理"字"，而是把文字切成一个个词元：一个汉字、一个英文词或词的一部分、一个标点，都可以是一个词元。Florence-2 这类模型还在词表中加入代表图上位置的特殊词元，所以同一个解码器既能写出文字，也能"写出"一个框的坐标。

容易混淆：词元不等于字：一个生僻汉字可能被切成几个词元，一个常见英文词可能只占一个。

对历史研究意味着什么：模型对生僻字、异体字的处理，部分取决于它的词表怎样切分这些字；使用通用大模型时的计费与长度上限，也按词元计算。

### 多模态大语言模型 | Multimodal Large Language Model

页面：D10

原文与别称：Multimodal Large Language Model；简称 MLLM；如 Gemini、GPT、Claude 等可以读图的对话模型

出现位置：讲义第三节 3.2

它解决什么问题：在对话中直接读图、回答关于图像的问题，包括录出图上的文字。

上传一页文书，请它把字录出来，它往往读得不错，对拍摄条件也较稳；但让它指出某行字在图上的位置、做版面分析，结果明显不如专用工具。

容易混淆：能"读出字"不等于能"给出坐标"；多数情况下它的输出无法逐行回到原图。

对历史研究意味着什么：适合快速初读，不适合作为最终录文；版本更新快，使用时记下版本与日期。

## 第五组：图像中的干扰

### 几何变形 | geometric distortion

页面：D15

原文与别称：geometric distortion；包括倾斜、旋转、透视、扭曲、曲面变形

出现位置：讲义第四节 4.1

它解决什么问题：说明拍照与装订造成的页面形状变化为什么会降低识读质量。

鷗外的两页照片中，靠近书脊的几行弯向中缝，矩形的检测框就会框进多余的部分或切掉一截。常见的补救是先"展平"页面，但只能挽回一部分损失。

容易混淆：几何变形改变的是形状，图像退化改变的是清晰度与颜色。

对历史研究意味着什么：能用图书馆的扫描件就不用手机照片；自己拍照时让书页平整、镜头垂直。

### 图像退化 | image degradation

页面：D16

原文与别称：image degradation；包括分辨率不足、模糊、噪声、压缩、对比度与颜色变化

出现位置：讲义第四节 4.2

它解决什么问题：说明成像之后图像质量的损失怎样影响识读。

同一页文书，高分辨率的彩色扫描与反复压缩的小图，识读结果可能完全不同。退化发生在图像上，与材料本身的残损不同。

容易混淆："图像退化"与"材料损伤"：前者可以通过重新拍摄改善，后者是材料本身的状况。

对历史研究意味着什么：保存与识读都应尽量使用原始的、未经压缩的图像。

### 二值化 | binarization

页面：D16

原文与别称：binarization；也叫黑白化、阈值化

出现位置：讲义第四节 4.2

它解决什么问题：把彩色或灰度图像变成只有黑白两色，使文字与背景对比鲜明。

二值化让许多识读工具更容易找到笔画，但会抹掉细节：《史德》一页的影印扫描就是黑白图像，"益"字的笔画粘连后被读成"盆"；敦煌写本的淡墨与朱笔批注，二值化后可能完全消失。

容易混淆：二值化是识读前的一个处理步骤，不应代替原图保存。

对历史研究意味着什么：原图以彩色或灰度保存；朱笔句读、批注的有无，本身就是重要信息。

## 第六组：检查与留痕

### 人工转录小样本 | manual transcription sample

页面：D19

原文与别称：manual transcription sample；也称人工标注样本、试点样本

出现位置：讲义第五节 5.1

它解决什么问题：在自己的材料上量出识读的错误，而不是相信工具的宣传或别人的评测。

从整批图像中分层挑出几页到几十页——清楚的、有注的、有残损的、潦草的都要有——由熟悉这种文字的人逐字转录，再与识读结果比对。

容易混淆：小样本不是要转录全部材料，而是用少量材料估计整批识读的质量。

对历史研究意味着什么：在大批使用识读结果之前，先做一次小样本，是对自己论证负责的最低要求。

### 参照转录 | ground truth

页面：D19

原文与别称：ground truth；也译"真值""基准转录"

出现位置：讲义第五节 5.1

它解决什么问题：为衡量识读结果提供一份公认正确的文本。

参照转录必须对着识读所用的同一张图像，按事先定好的录文规范做出来。用别的版本的电子文本代替，会把识读错误、版本差异与录入错误混在一起。

容易混淆："真值"只是在某一录文规范下的正确答案；换一种规范，参照就不同。

对历史研究意味着什么：参照转录本身也是一份学术成果，应注明转录者、规范与日期。

### 录文规范 | transcription guidelines

页面：D19

原文与别称：transcription guidelines；常见的两种取向为照录（diplomatic transcription）与规范化录文（normalized transcription）

出现位置：讲义第五节 5.1

它解决什么问题：事先规定转录时字形、缩写、句读、行款、残字、注文怎样处理。

照录尽量保留原页面貌，原字形、原拼写、缩写照录；规范化录文为便于阅读与检索统一写法。福尔杰莎士比亚图书馆为 1567 年的一封英文书信同时公开了两种转录：照录本作"oot{es}"，标出由缩写展开的字母；半照录本直接写出展开后的形式。

容易混淆：两种取向都是正当的学术选择，问题只在于同一份参照中混用。

对历史研究意味着什么：录文规范决定了"什么算错"；它应当写成文字，随参照转录一起保存。

### Unicode 规范化 | Unicode normalization

页面：D19

原文与别称：Unicode normalization；常用形式为 NFC

出现位置：讲义第五节 5.1

它解决什么问题：把编码方式不同、而按 Unicode 标准应视为同一字符的字统一起来，避免比较时把它们误算为错误。

同一个带附加符号的字母，可以编码为一个字符，也可以编码为"字母＋附加符号"两个字符；一部分汉字也有在标准中被视为等同的不同编码。比较参照转录与识读结果之前，两边都先做同一种规范化。

容易混淆："德"与"徳"在 Unicode 中是两个不同的字，规范化不会合并它们；要不要视为相同，由录文规范决定（参见第三周"字形归一化"）。

对历史研究意味着什么：计算错误率前说明做过什么规范化，数字才能被别人复核。

### 字符错误率 | Character Error Rate ⚠

页面：D20

原文与别称：Character Error Rate；简称 CER；按词计算时为词错误率（Word Error Rate，WER）

出现位置：讲义第五节 5.2

它解决什么问题：用一个数字衡量识读结果与参照转录之间的差距。

公式：CER = (S + D + I) / N

S、D、I 分别是替换、删除、插入的字数，N 是参照转录的总字数；分子就是第五周讲过的编辑距离。《史德》开篇 115 字中有 3 处替换，CER 约为 2.6%；把两处日本字形视为相同，则约为 0.87%。

课堂上你会看到：手算一行的 CER；比较工具生成的逐字对照报告。

容易混淆：CER 不分轻重，也看不见标点、读序与少数页面的严重失败；平均数与中位数可能讲出不同的故事。

对历史研究意味着什么：报告 CER 时同时说明录文规范、规范化方式、平均数与中位数，并逐条列出改变文义的错误。

### OCR 后处理 | post-OCR processing

页面：D21

原文与别称：post-OCR processing；也称 OCR 后校正（post-correction）

出现位置：讲义第五节 5.3

它解决什么问题：在不重新识读的情况下，自动发现并修改识读结果中的错字。

传统做法是查词典、找最接近的候选词；现在常把识读文本交给大语言模型修改，有时也同时给它看原图。研究结论并不一致：有的评测发现效果很差，经过专门训练的系统则能显著降低错误率。

容易混淆：后处理修改的是识读文本，不是重新看图识读；只看文本的模型只能根据"这里应该是什么字"来改。

对历史研究意味着什么：它是一次有风险的编辑：保留原始识读，列出每处改动，抽查并在小样本上验证。

### 过度纠正 | overcorrection

页面：D21

原文与别称：overcorrection；包括把词汇现代化（modernization）

出现位置：讲义第五节 5.3

它解决什么问题：说明后处理与视觉语言模型为什么会把本来正确的原文"改对"。

模型懂语言，会把罕见人名改成常见人名，把原书错字改成正字，把时代拼写改成今天的拼写；反方向的"过度古化"也存在，即替原文加上那个时代已经不用的古字母。

容易混淆：过度纠正不是普通的识读错误，它的结果通顺、像是对的。

对历史研究意味着什么：对校勘而言，原书的错字与时代写法本身是证据，被"改对"就等于抹去了证据。
