## 网页配置模型

原导入器仅请求站点根目录的`/models/`，GitHub Pages没有该目录时，报“使用本机启动脚本准备模型”。现在展开页面顶部“NDLOCR-Lite 模型配置”，即可下载、核对并缓存四个模型；也可直接识读，由OCR Worker按需取得缺少的模型。

页面和Worker共用`src/ndl/model-loader.ts`，先验证缓存字节，再尝试部署子路径、兼容的根目录资源及固定上游提交。模型保持既有PARSeq16版本及四个SHA-256，来源为[固定版本ndlocrlite-web](https://github.com/yuta1984/ndlocrlite-web/tree/50216ccc3e600f6d0d152862c5a201fdade78112/public/models)，署名和许可见导入器NOTICE。HTML、大小错误或指纹错误不会缓存。旧根目录缓存通过核验后迁移到当前子路径。

首次完整配置共154,009,122字节，约147MiB，只取得公开模型，不上传图像。可以取消配置，已经完成的模型保留，重试只取得缺少的模型。清除缓存须确认且只删除模型，保留材料、原件与校订。缓存不可用时允许当次识读，但不会声称完成持久配置。当前浏览器仍用ONNX Runtime Web单线程WASM与Worker；未切换24px模型或引入WebGPU。

模型缓存依附浏览器与站点来源；更换浏览器、地址或清除网站数据后需重配。首次须能访问模型来源，后续缓存复用不再连接模型来源；页面与ONNX运行时仍须可访问。模型权重不加入Git或导入器构建产物。
