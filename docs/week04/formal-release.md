## 发布检查

Node与pnpm按仓库版本锁定；第四周首次构建需要.NET 10，编译原Patchouli核心，并校验三份OCR权重的固定哈希。全站同时构建第三周、第四周及通用导入器，各自检查与测试通过后才组装site。

站点复制前排除local-only、private、inputs。四份预置PDF、原生SQLite与三份OCR模型使用精确文件及SHA-256白名单；其他PDF、数据库、ZIP及私有输入均拒绝发布。公开检查核对32页、页面映射、原版权说明、默认书库数量、模型哈希、第三周资源及导入器子路径。完整文件与哈希见站点release-manifest.json。

课堂操作和德教准备的详细说明仅保存在教师本地课程目录。浏览器首次加载WASM及PDF可能需要等待，方向键左右切换课件、上下翻PDF；文字输入框内保留编辑行为。临时页面和栏位调节仅改变呈现，不复制书库。

发布结果以GitHub Pages部署作业和实际网页复核为准，提交本说明不等于部署完成。恢复时在修复分支撤销本次主线提交，重跑整站检查并手动发布，保留第三周与原稿分支。
