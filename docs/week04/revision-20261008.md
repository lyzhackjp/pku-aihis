# 第四周演示与教案修订（2026-10-08）

以助教原有32页及知识组织原则版教案为主。本轮先形成教案插入方案，再经两个独立教学／技术评议与DeepSeek静态审核，处理意见后实施。审核报告、实际模型回应、可打印教案和具体研究主题材料另存课程本地目录。

## 页面与记录

- D25保留基本思想、编辑和图谱三种视图，增加多词表选择与本地TTL导入。每份词表分别保存原稿、来源及编辑稿；当前选择进入完整备份。旧版单词表草稿保留并迁入一次，错误编辑稿可以继续修改；文件解析失败不替换已有词表。
- D31“笔记与关系”复用D19核验、D20来源、D21卡片、D22关系和D23问题索引；切换在D31内部完成。Markdown与主线共用同一草稿，窗口内及跨标签更新同步。换材料不会自动重写已有来源笔记，须核对来源及范围。未放入的卡片切面板前提示确认。
- D31“备份与接续”复用D27原生ZIP恢复实验，并提供完整课程备份入口。原生ZIP已包含SQLite里的课程阅读轮次；独立Markdown、卡片、聊天、词表和概念导入稿由完整课程ZIP补足。

## ZIP辨型与恢复

两个ZIP文件选择入口都先检查结构：`pku-week04-material-pack/v1`清单表示材料追加；`patchouli-browser-backup-v1`表示原生库恢复；外层`patchouli.zip`、`reading-records.json`及可选`browser-drafts.json`表示完整课程恢复。完整包不要求外层另造`manifest.json`。

备份先在独立副本验证数据库、文件哈希与关系完整性，并核对外层阅读JSON与数据库记录一致，随后预览恢复对象并确认替换。外层阅读JSON是核查副本，不作为另一份导入源。取消不改变当前库，持久化失败回退当前库及独立草稿；独立草稿清单不包含模型配置或密钥。

## 教案与公开范围

教案保留助教原正文，在对应段落下补“教师注”“概念注”，给出主线逐步操作与填写示例；D10增补四种工具对象、BibTeX引用键、FTS行标识和三表关联，D12增补描述规则、MARC交换字段、CSL数据／样式／输出的实例。D10、D12页面结构和组件未改。概念附录更新为134条，仍可本地编辑后导入。

本机Zotero、Obsidian演示计划单独保存。默认仍为助教原有4条题录、4份PDF；具体教师研究材料、预写产物、主题词表和完整导入包不进入代码库或公开站点。独立Agent功能没有并入本轮课件。

验收区分实际运行与静态核对；本地完整示范包用于恢复测试，不作为公开测试夹具。测试入口为`apps/week04/scripts/check-week04-revision.mjs`，通过环境变量指定本地包及词表。
