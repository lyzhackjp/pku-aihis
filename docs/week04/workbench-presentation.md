# 助教工作台的课堂显示

PDF阅读使用上下方向键及PageUp／PageDown翻页。左右方向键留给课件；输入框、下拉选择、编辑正文和输入法组合时保持原本的按键行为。

工作台标题栏的“⤢”在浏览器顶层临时放大当前实例；“返回课件”或Escape回到原栏位。临时页面复用当前书库、所选材料、原页和编辑草稿，不重新创建一个书库副本。

带助教工作台的页头提供“工作台宽度”，可调至45%–90%，也可恢复助教默认布局。默认排版保持原样；仅在手动调节后覆盖左右栏比例。该调节是演示显示状态，不写入研究记录。

课堂备份仍从右上角“材料包／备份”下载。私人材料、德教阅读填写包与模型核查回应仅保存在本地准备目录，不进入代码库。
