# 第五周实施设计

候选，未经教师确认。2026-10-11。依据本机当前讲义，输入指纹见input-baseline.json。

原附件26页只有6页实现。本轮补齐全部页面，采用既有四栏流程：输入→中间结果→结构或数值→回到依据。复杂机制方案仍保留比较：切分滑块对照优于仅点亮分隔符，因它能暴露真实切点；集合四栏优于两个静态查询，因它保留交集与代入；实体规则切换优于两张预生成图，因学生可修改异称并观察关系汇集。RAG历史采用四格阶段图；GraphRAG索引采用分步图与原文回查；不需要为每个图引入额外图库。此选型按本次“完成开发”的授权落实，待教师看候选结果后调整。

26页覆盖160分钟；D24、D25为贯穿与概念入口，不另加课时。休息安排与教师操作见apps/week05/README.md。页面文字、过渡句、模式、来源、备注统一从page-map生成。概念表由当前Typst重新转换，共20条，计算类公式用纯文本呈现，教师可对照原表复核。

贯穿页沿材料身份、切分、字面检索、上下文预算、人工逐句核读和有限回答走六阶段。三份材料有原文、电子文本身份和出处；原文阅读器可在网络中断时读本地节录。字面检索无法代替跨语言语义检索，日文异称按人工表处理。

正式工程为Stencil打包＋原生Web Components复用模块；没有把已验证的原型状态重新写成第二套JSX，也没有移植帕秋莉大型工作台。模型接入单独保留实际工具循环和失败状态；教学替代的预写回答与真实调用记录分开。
