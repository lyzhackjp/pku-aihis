# 语料追加与混合库检索

2026-09-24。用户要求保留详细版主线，并把新语料导入从整库替换改为追加。入口沿用PR #6右上角“语料库管理”，支持一次多选JSON/JSONL；每批合计不超过130MB，可继续分批加入。

## 导入规则

- 新编号追加到已有记录之后，不清空27条默认史料或此前导入的其他类别。
- 同编号、正文和来源相同：重复记录跳过。若已有记录缺向量，配套JSON中的向量补到原记录，保留原有出处和其他字段；再次导入纯文本不会抹掉向量。
- 同编号但正文、作者、篇名或出处定位不同：报告冲突编号，本批所有文件均不写入。先核对或区分编号，再导入。
- 同一个检索库只使用一套兼容向量编码配置。模型、固定修订、维数、量化、池化、归一化、截断长度等不一致时拒绝混用；仅运行时间、设备等元数据差异不构成冲突。可先追加纯文本或重新生成兼容向量。
- 保留原来的预计算查询，并加入新包中的同模型查询；相同查询文字不重复。
- 每批全部解析与核验后一次提交。导入失败不造成清库或部分文件先写入；成功后索引版本更新，旧检索状态清空并重建索引。D22静态引文关系继续保留。

文件仍只在当前浏览器页面内存中处理，刷新恢复默认库。UI明确显示总记录数和有兼容向量的记录数：关键词、全文和RAG关键词候选覆盖当前全库；向量一路只覆盖已经附向量的记录；RRF仍可保留来自关键词一路的纯文本记录。导入不自动更新AnythingLLM或外部数据库，相关页面继续提示其实际库范围。
