## 因实测而改的计算（tests 47/47）

1. 时间线解析：补表格行与只到年的日期（Kimi 的写法）；去掉只有月份的小标题；日期单独一行、事项在下一行的照样接上。
2. 时间线预填：措辞不同而日期精确对得上的（基准行区间不超过一个月、文字二字组 Jaccard ≥ 0.03）加 0.25。
3. C02B 比较：原用一对一配对，模型按句列异文时会冤枉它（DeepSeek 一次被算作"召回 4/20"）；改为"覆盖"——把模型每行的甲、乙文字逐词定位回两本，程序一处落在定位范围里就算列到。改后 DeepSeek 20/20，Kimi 19/20（漏 V17）。
4. D12 页码核对：只认"原刊第×页"，接受区间"第198—199页"；所据材料栏里别的书的页码不算。
5. 拆句时去掉 Markdown 的粗体与标题记号（只影响显示与标注用的句子）。
