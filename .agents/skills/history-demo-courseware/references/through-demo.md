# 贯穿演示页（layout: through）

## 作用

让一组材料承接整讲：讲义各节分别回答它的一道检查，学生或教师在贯穿页上把同一份记录一步步做完。第四周 D31“德教贯穿”与第五周 D24 是两个已发布的先例。

## 设计前先看上一周线上贯穿页

教师要求“UI 设计参考第四周实际发布的贯穿页”。动手前用浏览器打开上一周线上贯穿页截图（书库需等启动完成），照其骨架设计，而不是凭记忆。

## 骨架（第五周 D24 定型）

```
┌ 左：工作台 ───────────────────────────────┬ 右：研究链侧栏（约 320px，左细线分隔）┐
│ [工作区：n 阶段名] [原件与正文：题名] [本轮判断记录↓] │ 德教研究：用同一库走完……          │
│ ┌───────────────────────────────────────┐ │ 问题起点（可编辑）                │
│ │ 当前阶段的工作区（书库式表格、检索表等）  │ │ 1 材料身份 │ 2 范围与切分        │
│ │                                         │ │ 3 检索     │ 4 图与关系          │
│ └───────────────────────────────────────┘ │ … 两列阶段按钮                    │
│ 页脚一句：来源与材料位置                     │ 阶段提示（灰底）                   │
│                                             │ 已导入材料（按性质的小标签）        │
│                                             │ 本轮进度（范围、单元、检索、嵌入…） │
│                                             │ [导出本轮判断] [完整备份]          │
└─────────────────────────────────────────────┴───────────────────────────────────┘
```

- **工作区**：材料身份用书库式题录表（本轮勾选、性质、年份、作者、题名、出处、文本块、原件；性质筛选与搜索；按史料、二手文献、课程材料、教师研究产物排序）。
- **原件与正文**：点题名、检索结果或交给模型的单元，显示题录字段与上一周正文块，可打开原页。
- **本轮判断记录**：问题、范围、检索问题、保留单元、自己的判断、模型候选、逐句核读比例，加一段自由记录。
- 未导入时：左侧只显示导入说明与“选择德教包”大按钮，右侧阶段按钮灰显。

## 阶段与数据

- 阶段 4—7 个，每个复用对应讲解页的计算；前一阶段的结果决定后一阶段的输入（范围 → 检索单元 → 检索保留 → 图／模型输入 → 核读）。
- 长文本块按“空行→换行→句号→空格→逐字”细分为检索单元，原块编号不变（“原块~序号”）。
- 检索两步：BM25 全量“找得全”，前 N 个现场嵌入“排得准”；页面写明实际编码了多少单元、来自哪些材料、用时，以及未编码单元没有参与语义排序。
- 教师研究产物默认不进检索，须显式打开。
- 先写自己的判断才可发送给模型；接续上一周的阅读轮次（显示任务与所读题录）。
- 重做界面时保留内部方法名与数据属性（如 `d24Scope`、`data-scope`、`data-set="through"`、`d24-bm25`、`d24-dense`、`d24-read`），已有集成检查才能继续使用。

## 材料诚实

- 德教全量、教师稿、未刊稿只在本机导入，不进公开构建；完整备份只在本机生成。
- 讲义只有转述的材料，显示“讲义转述”；保存的运行记录标为回放；未运行显示待运行。
