# 贯穿演示页（layout: through）

## 作用

让一组材料承接整讲：讲义各节分别回答它的一道检查，学生在贯穿页上把同一份记录一步步填完。它是“本讲在做什么”的地图，也是课后可以带走的作业记录。第四周的先例是 D31“德教贯穿”：同一助教工作台按材料身份、范围与队列、独立阅读、机器比较、笔记与关系、修订复核、备份接续组织侧栏。

## 选题

按优先顺序：

1. 讲义导入自己提出的问题或错例（第五周：“这几位作者怎样看待史料对叙述者的约束？”及错例回答“三人都认为历史叙述必须完全服从史料”）。
2. 教师提供的研究主题与材料包（第四周德教）。
3. 前一周贯穿材料的延续（让学生看到同一材料在新技术下的变化）。

选定后，从讲义各节找出这组材料被检查的那一步，写成 4—7 个阶段；页表中相应讲解页的 `through` 字段写阶段名。

## 版式

```
┌ 侧栏（240px）────────┬ 主区 ────────────────────────────┐
│ 问题                  │ n · 阶段名：本阶段问题   讲解页 Dxx │
│ 待检查的回答（红线）   │ 本阶段的操作与中间结果             │
│ 1 阶段 ✓已记录        │ （复用讲解页的计算，范围缩到本材料）│
│ 2 阶段                │                                   │
│ …                     │ [记下这一步，进入下一步 →]         │
│ 导出记录 .md ｜ 清空   │                                   │
└──────────────────────┴───────────────────────────────────┘
```

- 侧栏始终显示问题与待检查对象；阶段按钮显示完成状态。
- 主区每个阶段只做一件事，计算复用对应讲解页的同一函数（第五周第 3 阶段与 D11 共用集合度量），结果用同一材料。
- 每个阶段标出“讲解页 Dxx”，可跳去再返回；顶栏“贯穿检查”按钮随时进出。
- 阶段之间共享状态：前一阶段的选择决定后一阶段的输入（第五周：切分方式决定候选，候选决定上下文，上下文决定可下的判断）。
- 最后一个阶段让学生写出自己的有限论断，并附自查清单；整份记录可导出 Markdown。
- 记录存当前浏览器；正式版若需长期保存或收作业，按第四周完整备份的做法另行设计。

## 材料诚实

- 原文片段照所据版本录入，标所据电子文本与位置。
- 讲义只有转述的材料，显示“讲义转述，非原文；原文待接入”，不参与计算。
- 预设的切分结果、判断与示例句标为教学构造；预先保存的运行记录标为保存结果回放，未运行时显示“待课前运行”。
- 教师未刊研究与私人材料只在本地包中使用，不进公开构建。

## 第五周原型

`week05/prototype/week05-labs.js` 的 `ThroughWorkbench`：材料身份 → 切分与证据 → 取回与相似度 → 进入上下文 → 逐句判定 → 有限论断，共六阶段，对应 D03、D09、D11、D15、D16、D23。阿克顿与森鴎外原文待教师提供。
