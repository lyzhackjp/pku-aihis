# 页面模式（第五周定型）

源码：`apps/week05/src/assets/revision/revision-labs.js`（各页 `case "Dxx"`）、`chapters.js`、`revision.css`。新一周优先复用这些模式与样式类，再按内容改。

## 1 阶段卡（讲解“发展脉络／分类”的页：D01、D02、D10、D18、D21）

数据放在 `chapters.js`：`{ lead, stages:[{ name, tag, short, quote, cite, paper, subs:[{ name, quote, cite, paper, example, explain, links }] }] }`。

- `paper = { en, zh, cite, note }`：英文原句、中文学术翻译、出处（作者、题名、arXiv 版本或刊期、节次）、注释（原句指什么、原文笔误照录、与讲义概括的关系、读取深度）。
- `quote / cite`：讲义原句与节次；`example`：本讲材料中的具体例子（数值须实际算过）；`links`：去往演示页。
- 版式：时间线式阶段条 → “论文／综述”与“讲义”两栏引文 → 小阶段标签 → 卡片（原文、注释、讲义、本讲例子、说明、链接）。左侧阶段卡、右侧演示时用 `chapter(true)` 紧凑模式。
- 原句来源优先级：原论文摘要或正文节 → 官方文档 → 教材在线版。整理成 `papers.json` 后用 `scripts/check-quotes.mjs` 对抓下来的原文逐句核对。

## 2 切分实验（D04）

左窄栏：块大小、重叠、各切法块数小表、可改文本（折叠）。右侧：切法标签（显示块数与依据）→ 一行摘要 → 左右两栏：“切点落在哪里”（全文、✂ 切点、相邻块底色交替）与结构化片段表（块、依据、字符范围、字数、与前块重叠、文本）；点表格一行，左侧对应块加框。

## 3 带参数的算法页（D06 语义切分）

- 视图标签：史料实际试跑／八种做法总览／论文原图与结果。
- 控件：`fieldset` 分组，“切分做法”一组；做法自己的参数放在缩进的子组里，图例写“（嵌入断点的选项）”；只显示当前做法的参数；按钮用 `.seg-btns` 小号分段按钮。
- 距离折线＋阈值线；预计算向量与浏览器重算的来源在页面写明。

## 4 处理记录导航（D08）

左：方法与参数；中：Markdown 式处理记录（## 1 输入原文 / ## 2 补写／编码 / ## 3 片段与表示 / ## 4 查询与原页）；右：示意图节点。点节点或“动态走处理过程”高亮对应一节。执行后对照“问题·原片段”与“问题·加上下文后”的余弦，并显示发送字数与各步用时。

## 5 版本对照与去重（D14）

真实版本对：扫描转写 ↔ 公开电子文本（自动对齐最相近的连续句），显示精确 J、最小哈希估计、去标点后的逐字差异、按阈值的机器判断与人工决定（保留两版／合并注明／删去副本）。

## 6 智能体与协作（D21）

- 黑板：本机实现三层黑板（片段／人物与概念／论断与缺口）与三个确定性知识源，控制按“最新变化”选择知识源，可逐步前后翻看；近年 LLM 黑板与 API 试跑放折叠区。
- 蚂蚁系统：在检索取回的片段上解旅行商问题（d = 1 − 字二元组杰卡德），参数按原文定义，显示信息素矩阵与最短阅读顺序；说明它求出的是阅读顺序，不是历史关系。

## 7 多轮阅读（D22）

六类任务各有预置提示词（可改）；先写自己的判断；冻结范围为 BM25 前 N 段并列出；回答中的 `[片段ID]` 渲染为可点开原页的按钮；同一范围内多轮追问；私有材料须勾选云端许可。

## 8 题录字段（D03）

字段按“是谁／在哪／读到哪”着色；从所选材料带入已知字段；记入题录表；导出 CSL JSON。

## 9 材料栏

`selection()`：一行，“材料”“片段（含整份材料）”“共 N 段”，右端两个小按钮（导入本机材料、通用导入页）；放在栏内或窄面板时隐藏导入按钮。
