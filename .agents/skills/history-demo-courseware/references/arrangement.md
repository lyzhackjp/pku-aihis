# 第四周的设计与排布

来源：pku-aihis `docs/week04/design.md`（文案风格约定、全局规则）、`transitions.json`、`review-20261007.md`（七项复核）、`diagram-navigation.md`、`workbench-review.md`、`option-b-trial.md`（助教版方案 B 正式发布）、`apps/week04/src/components/deck-container` 与 `deck-slide`。

## 每页的固定部件

| 部件 | 约定 |
|---|---|
| kicker | `Dxx / 教案 节次`；封面、贯穿、附录写 `Dxx / 导入`、`Dxx / 贯穿`、`Dxx / 附录` |
| 标题 | 一行可读完；hero 页由主体大字承担 |
| 过渡句 | 标题下一行，承接上一页、引出本页（第四周 31 页集中写在 transitions.json，现并入页表 `transition` 字段） |
| 运行模式 | 右上角小标签，与页脚一致 |
| 主体 | 按 layout |
| 页脚 | 一句，以页号开头，交代来源与运行模式 |
| 备注 | 目的／范例引导／机制背景，演讲者窗口显示，可临时修改（只存本次会话） |

## 外壳（deck-container）

- 顶栏：课程名、课程地图、各类全局入口（第四周有模型接入、导入 PDF、材料包／备份等），右侧固定 **贯穿入口** 与 **概念入口**：点击进入对应页，并记住来处；在该页时按钮显示“返回原页”。
- 底栏：上一页／页码／下一页，提示“方向键翻页 · Esc 地图 · P 备注 · B 静态”。
- 键盘：方向键、PageUp/PageDown 翻页，Home/End 首尾，Esc 课程地图，P 演讲者窗口，B 低功耗静态。焦点在 input、textarea、select 或输入法组字时不响应。
- 演讲者窗口：同一页面加 `?presenter=1`，以课程专用 BroadcastChannel 同步（频道名带周次与日期，避免跨周串台）；可宫格选页、计时、看下一页；观众屏关闭后可恢复。
- URL 带 `#Dxx`，刷新后回到同一页。

## 设计取舍（第四周已定，后续沿用）

1. **同一套工具上讲理念，不做教学／工具双模式。** 工具页直接是工作台；理念由示意图导航到实际操作区，而不是弹出讲解。
2. **示意图即导航。** 三层柱体、实体关系图等示意图的节点可点击，切换到同一应用的对应界面；返回时恢复原界面、查询与草稿。
3. **紧凑。** 工作台的导航、状态、保存／返回集中在单行顶栏，把空间留给主内容。
4. **软件尚未实现的教学功能用独立示例或可视化**，不在真实工具里加虚构页面。
5. **贯穿与概念两个入口随时可达**（第四周为“德教贯穿”D31 与“概念附录”D30）。
6. 所有示意图有进入、连线或层级动画；B 静态与系统“减少动态效果”时关闭。
7. 页数与页号经教师批准后固定；增删页先改页表并说明理由。

## 文案风格（实现代理必读）

1. 正向表述优先。避免“不等于”“不把 X 当成 Y”式的一句话否定；需要辨析时写一个完整段落，交代两个概念各自的背景、区别与关联。拿不准用“可能”“在……情况下”。
2. 恰当使用引言。名家原话照抄原文，含原文语言与出处行。
3. 注重归纳。多例并列后用一两句收出共同结论。
4. 后页依赖前页。概念首次出现即给定义或案例；备注里标明本页机制被哪些后页复用。
5. 备注三段式；页脚一句来源／模式说明。
6. 内容放不下先删减或拆页，不压字号（投屏正文 ≥ 16px，图表标签 ≥ 13px）。

## 视觉变量

沿用第三、四周 `global/app.css`：纸色 `#f4f3ee`、墨色 `#20272e`、强调 IKB `#164ec7`、深色页 `#1c2835`；Inter／苹方／微软雅黑／Noto Sans SC；直角、细线，不用阴影与渐变。四栏页的说明块浅蓝底左竖线，动手观察条米黄底。
