# 概念表页（layout: concepts）

## 来源与转换

学生用的《概念讲解表》（Typst）是唯一原稿。用

```
node scripts/typ-concepts-to-md.mjs 概念讲解表.typ page-map.json weekXX/plan
```

生成 `concepts.md`（可编辑原稿）与 `glossary.json`（课件数据）。转换规则：

| 概念表 Typst | 原稿 Markdown | 页面 |
|---|---|---|
| `= 第一组：……` | `## 第一组：……` | 分组标题，侧栏分组 |
| `== 名称` | `### 名称 \| English` | 卡片标题与英文名（取“原文与别称”中第一个西文名） |
| `#field[原文与别称][…]` 等六个字段 | `原文与别称：…` 字段行 | 卡片中的定义列表 |
| 正文段落 | 段落 | 卡片讲解 |
| `$ … $` 公式 | `公式：…`（纯文本近似），标题加 ⚠ | 等宽显示，并提示对照原表复核 |
| `= 前几周已讲` 列表 | `## 前几周已讲` 列表 | 页末清单 |
| （页表 `concepts` 字段） | `页面：Dxx` | “首次出现”回链 |

六个字段：原文与别称、出现位置、它解决什么问题、课堂上你会看到、容易混淆、对历史研究意味着什么。字段顺序：前三个在讲解之前，后三个在讲解之后。

原稿格式兼容第四周 `concept-appendix.md`（`## 分类`、`### 中文术语 | English`、`页面：Dxx`、`参考：URL`），只是多了字段行。

## 页面

- 左侧：搜索框（中文、英文、释义全文）、按组列出的词条、导入修改后的 `.md／.json`、恢复课程原表。
- 右侧：分组卡片；每张显示首次出现页（可点击，进入后顶栏按钮变为“返回原页”）、字段与讲解。
- 顶栏“概念表”按钮随时进入，再点返回来处。
- 导入失败时保留原表并显示原因；导入的原稿只作数据，不作模型指令。
- 每条概念都必须有首次出现页；页表改动后重新转换（`check-page-map.mjs` 会检查）。

## 写概念页时自查

1. 条目名与讲义 `#term[…]` 完全一致。
2. 公式条目已对照原表复核，或保留 ⚠。
3. “前几周已讲”只列名称与出处，不重复释义。
4. 首次出现页指向的页确实首次讲到这个概念。

## 第五周定型（v5）

- 页面每条概念五块：① 一句话定义（`definition`，≤40 字，检查脚本校验）＋“它解决什么问题”；② 机制或公式（`formulaHtml`，用 `.fr` 分式等内置排版；讲解段落折叠）；③ 本讲例子＋“到 Dxx 动手看”；④ 易混处；⑤ 对历史研究的意义。原文与别称、出现位置放标题行。
- 侧栏按组列出，选中项浅底深字（避免全局 `button.on` 白字）。
