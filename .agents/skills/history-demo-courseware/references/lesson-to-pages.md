# 从讲义到页表

## 一、读讲义

`node scripts/outline-lesson.mjs 讲义.typ` 列出：

| 讲义里的标记 | 在页表中的去向 |
|---|---|
| `= 节（N分钟）`、`== 小节（N分钟）` | `section`、`minutes`；约每 5—8 分钟一页，练习长的小节可占两页 |
| `#figure(... ) <fig-xxx>` | 页面来源；写进 `anchor`。讲义图里的固定数值就是验收用的反例 |
| `#term[概念]` | 首次出现页的 `concepts`；概念表回链据此生成 |
| `#grasp[...]` | 页面要让学生看到的程度，写进 `observable_output` 与备注“目的” |
| “请同学……（N 分钟）” | `student_operation`；练习时间计入该页 `minutes` |
| `#src[...]` | `lesson_evidence` 与页脚来源；读取深度照抄（“摘要”“全文”“未运行”） |
| `#note[...]` | 备注“机制背景”或页面边界说明 |
| 附录“课堂调度表”“阻碍与替代路径” | 核对页序与时长；替代路径写进运行模式失败时的显示 |

讲义注明“教学构造”“示意数值”“未运行”“厂商自报”的地方，页面同样标注，不升级为实测。

## 二、页表字段

见 `templates/page-map.schema.json`。必填：

- `id`：D00 起连续编号；封面 D00，倒数第二页贯穿页，最后一页概念页。
- `section`、`anchor`：教案节次与讲义锚点（标题或 @图标签）。
- `title`：页面标题，一行可读完。
- `layout`：`hero / flow4 / diagram / workbench / through / concepts`。
- `transition`：标题下的过渡句，承接上一页、引出本页，正向表述。
- `question`：本页回答的一个问题（四栏页显示在步骤轨左侧）。
- `steps`：四栏页的步骤名（3—6 个，默认 4 个），也是贯穿页的阶段名。
- `student_operation`、`observable_output`、`lesson_evidence`：五项对应的后三项。
- `mode`：运行模式，含六档之一的字样。
- `notes`：`purpose / guide / mechanism` 三段。
- `footer`：以页号开头的一句来源与模式说明。
- `concepts`：本页首次出现的概念（与概念表条目名一致）。
- `through`：本页推进贯穿页的哪一步（可空）。
- `options`：复杂机制的 A/B 方案与推荐（可空）。
- `status`：`planned`（只在页表）或 `prototype`（原型已实现）或 `formal`（正式工程已实现）。

## 三、分页原则

1. 一页一个主要动作。讲义一个小节若有“计算＋讨论风险”两件事，分两页（如第五周 D11 集合度量与 D14 去重的版本风险）。
2. 讲义的同一张图只落一页；回顾性的图（前几周已讲）合成一页 `diagram`。
3. 论文结果页只放论文报告的数字和条件，不复现、不外推；“本讲推论”与“论文结论”分开写。
4. 学生练习页优先做成可操作的页，让练习的中间结果在页面上可见。
5. 课堂替代路径（服务不可用、超时）在页面上有对应的显示状态：如“待课前运行”“读取保存记录”。
6. 写完运行 `scripts/check-page-map.mjs`：概念与图都有落页，时长与讲义相差不超过一成，过渡句没有否定式。

## 四、第五周的落实

第五周讲义 160 分钟净教学，页表 26 页（D00—D25），其中 D24 贯穿、D25 概念表。复杂机制页 D05、D11、D16、D19 给出 A/B 方案，均推荐四栏流程。详见 `week05/plan/page-map.json` 与 `design.md`。
