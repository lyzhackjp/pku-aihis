# 验收清单

验证真正影响教学的行为，记录实际测试对象与版本；构建成功不等于内容核查通过，没运行、跳过、不适用、失败分别写明。

## 必查（原型与正式版都查）

| 类别 | 检查 |
|---|---|
| 页表互锁 | 页面编号、数量与页表一致；入口指向的页存在；`check-page-map.mjs` 无错误 |
| 固定数值 | 讲义图中的每个数值反例，在页面函数与界面上都能复现（第五周：J=3/18、4/17，二元组 1/22、2/21，编辑距离 1/1/5，P_w=0.75、R_w=0.50） |
| 交互 | 改输入后各列同步重算；焦点与光标保留；输入框内方向键不翻页；输入法组字不翻页 |
| 入口 | 贯穿、概念入口进入与“返回原页”；从卡片回链进入讲解页 |
| 状态 | 贯穿记录刷新后保留；清空可恢复默认；导出文件内容正确 |
| 布局 | 1440×900 与 390×844 各页截图；无页面横向溢出；宽屏列内滚动，窄屏整页滚动 |
| 双屏 | 演讲者窗口随观众屏同步；从演讲者窗口翻页，观众屏跟随 |
| 控制台 | 无 pageerror、无 console.error |
| 诚实 | 运行模式标签与页脚一致；转述、构造、未运行的内容在页面上可见地标注 |

## 正式版另查

- Pages 子路径与首次访问资源；离线或断网时的降级显示。
- 需要服务的页面（模型、检索服务）在服务缺席时显示真实失败，不用构造输出顶替。
- 发布白名单：不含未刊稿、教师私人材料、模型权重、密钥与本机路径。
