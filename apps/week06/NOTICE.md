# 来源与许可

候选，未经教师确认。

- NDLOCR-Lite 浏览器代码直接引用 `../material-importer/src/ndl`，沿用该目录 NOTICE.md 与 CC BY 4.0 归属；模型固定表也直接引用。共用检测器只暴露其已实现的行类与文本块，17类清单不表示该浏览器适配器已返回全部17类。D03振假名演示使用已有 XML；公开页实时结果受共用实现限制。
- PaddleOCR 官方 paddleocr-js core 0.4.2，固定提交与逐文件原始哈希见 `src/engines/paddle-upstream/UPSTREAM.json`，Apache-2.0 完整许可随目录。仅 `models/det.ts` 添加概率图输出；其余为原文件。固定 inference.yml 来自与模型相同的 HF revision，识读使用其中官方字典。
- transformers.js 3.8.1、ONNX Runtime Web、OpenCV.js、clipper-lib、js-yaml 与 Stencil/Vite/TypeScript 的版本见 package.json 与 pnpm-lock.yaml；运行库许可证随包保留。
- dots.ocr README 与公开示例图按官方 MIT 来源使用；完整 MIT 文本在素材目录 LICENSE.dots-ocr。Kraken 官方图按 Apache-2.0；MEDUSA 图按 CC BY 4.0。各图来源链接、取得记录与指纹均见 sources.json。
- Folger EMMO 的照录、半照录及 TEI 为 CC BY-SA 4.0；原件记录见 EMMO 链接。转录纯文本转换说明保留在 JSON 内，D19 HTML保留缩写标记。高清图尚未取得，预览图不用于逐字核读。
- 公开《史德》、P.2011、P.2510 为 Commons 标示公共领域的扫描副本；東寺百合文書图块按 CC BY 2.1 日本，署名“京都府立京都学・歴彩館 東寺百合文書WEB から”。课堂变形为浏览器派生，另存处理参数。
- 讲义只公开本任务所需摘录与概念表转换，不收录完整讲义或教师私有页影、XML、裁切图。所有实际课堂导出留在教师本机。
