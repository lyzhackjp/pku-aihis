# 第六周 · 文从何来

候选，未经教师确认。26 页、34 条概念、净教学 160 分钟。开发分支 `feat/week06-courseware`；尚未发布。

## 本机打开

双击课程 `第六周/demo/启动第六周演示.command`。本机 URL 为 `http://127.0.0.1:8776/pku-aihis/week06/?local=1`；去掉 `?local=1` 即按公开入口操作。不要直接打开 HTML。需要 Node ≥22、pnpm、Python 3；依赖按锁文件安装，启动器只构建缺失的网页，不下载识读权重。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm preview
```

构建同时构建共用 material-importer（其依赖须先按自己的锁文件安装）。页面外壳、键盘与演讲者窗口沿用第五周；存储与广播使用 week06 前缀。素材导入页可传入图像与项目，PDF 项目仍需选择页面另导出 PNG/JPEG。

| 页 | 操作与产物 |

方向键／空格翻页，输入框和组字期间不翻页；B 静态模式；右上角打开演讲者窗口，双向同步。贯穿与概念入口再次点击可返回原页。图层区域可 Tab 聚焦、方向键切换、Enter 选中；缩放与拖动仅改变视图。

## 模式与材料

浏览器实时、本机服务实时、按共用 API 实际调用、保存结果回放、教学构造分别标注。实际模型本次均未运行；首次点击模型按钮才下载固定 revision/SHA-256 的权重。模型失败不生成示例答案。NDL 引用共用导入页实现；PP 使用固定的 PaddleOCR 官方 JS 核心，额外暴露概率图；Florence 固定 transformers.js 3.8.1 和 q8 模型，约262.2 MiB，语言能力当场检验。

API Key 仅在当前页面内存；关闭或刷新须重填。ChatGPT/Gemini 的兼容接口与模型名由教师配置，页面不会自动调用。勾选授权前不发送；可明确填写裁切范围。请求、回复、usage、耗时保存在本机 IndexedDB，可导出。带私有材料的导出也属于私有材料。

公开素材身份、许可、图像位置与指纹见 `src/assets/materials/sources.json`。1926《史德》不是教师1988版；東寺图像是0001页右侧图块；Folger仅取得 EMMO 转录与预览小图，高清页影待取得；鷗外和 P.2965 仍待准备。无公开替代时显示“需本机材料”。本机原件由预览器白名单从课程目录读取，绝不复制入 src 或 www。
