## 本机打开

双击课程 `第六周/demo/启动第六周演示.command`；本机入口 `http://127.0.0.1:8776/pku-aihis/week06/?local=1`。去掉 `?local=1` 可查看公开入口。需要Node≥22、pnpm、Python3；不要直接打开HTML。

在 `apps/week06` 内运行：
```sh
pnpm install --frozen-lockfile
pnpm build
pnpm preview
```
构建同时构建共用material-importer，其依赖须预先按锁文件安装。构建不下载模型，不调用OCR。

## 模型、API与记录

顶栏“课前检查”打开独立 `preflight.html`。NDL四个文件、PP两个文件、可选Florence与dots服务分别报告缓存、SHA、会话、公开图热身及真实错误，导出Markdown／JSON。检查必须在教师实际授课用Chrome配置中由教师触发；开发测试的隔离浏览器不能证明教师缓存已就绪。

课件NDL／PP运行按钮只读取已校验的缓存，缺失时引导去检查页主动下载。共享导入器的既有下载入口仍可用。Florence可选，约262.2MiB；dots权重本轮未下载。模型没有结果时显示待运行，官方图与构造输入分别标注。

共用API预设及依据见 `modules/history-demo/ocr/api-presets.json`。D12固定选择Kimi K3，官方API型号为 `kimi-k3`；先填Key，做内置“史德 7141”看图测试，再勾选发送范围。官方地址下的旧显示名称“Kimi K3”会规范为API型号，404保留原文并提示检查实际型号与账号权限。Gemini／ChatGPT栏由教师粘贴网页版回答。D21新增“接入 DeepSeek V4.1 Flash”，官方API型号为 `deepseek-flash`。材料／配置改变后重新同意；Key只在内存，刷新清除。请求、回复、usage、耗时与错误保存在本机，导出剔除Key。2026-10-22教师反馈Kimi“看图测试：已通过”；这不代表已经验证课程整页调用。DeepSeek本轮只验证请求构造与替身协议，尚无真实接口反馈。

D22会话下拉框只列当前页影指纹相同的记录，默认选最近加入的整页记录；换用另一页记录须先切材料。文件导入继续保留指纹核对，避免把异页文字贴到当前页。

D04的 `kraken-d04/` 是lesson-agent提供的云端CPU实跑回放（固定Kraken bb48721，三份输入、三档阈值）；Codex在本机核对数据、图像指纹和浏览器交互，没有重新运行Kraken。D11新增dots.ocr公开页云端实跑回放；本机配置脚本另见 `tools/dots-ocr-service/README.md`，本轮未安装或运行Mac模型。D07的481个算子仍是ONNX静态形状元数据。

参照必须登记出处与规范；人工核对／据翻刻还要核对人、日期和逐字复核声明。未核机器稿不显示评测CER。CER按Unicode码点（NFC）计算。逐处修改后的稿件保留原始记录，但不继承原识读分数。
