候选，未经教师确认。2026-10-11。26页D00—D25，全部实现；对应本机第五周讲义与20条概念讲解表。输入指纹见 `docs/week05/input-baseline.json`，逐页与机制见 `docs/week05/page-map.json`，框架改进见 `docs/week05/framework-analysis.md`。

## 打开

安装Node 24及pnpm后，在本目录运行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm run check
pnpm test
pnpm build
pnpm preview
```

打开 **http://127.0.0.1:8775/pku-aihis/week05/**。构建产物需要HTTP服务；不能把源码HTML双击视为完整构建验收。已有构建时，可双击课程目录 `第五周/demo/启动第五周演示.command`。

方向键翻页，Esc地图，P演讲者窗口，B关闭动效；输入与组字保持原编辑行为。顶栏贯穿检查／概念表再次点击返回原页。来源按钮打开本地节录及完整材料字段，链接另开公开原文。窄屏采用整页滚动。

## 模型与记录

D22默认本机兼容地址 `http://127.0.0.1:11434/v1`。输入模型名后“实际模型对照”使用同库同模型：固定路径先检索，智能体通过search决定检索；每路最多3次模型调用、每次输出上限600token、temperature=0。记录库SHA-256、查询、进入的片段、完整请求与实际输出、工具调用、API usage与耗时。API Key只保留页面内存，不进存储与导出。模型接口若失败，会保留实际错误，不用构造答案覆盖。

“运行本地检索对照”真实执行两次字面检索，第二查询由人预设，回答明确标教学构造；它不是智能体模型运行。模型工具接入的自动检查用测试替身，不能证明真实模型答案。此机11434与11435本轮没有可用服务，**真实模型生成未实测**。

导出的JSON记录可在D22重读；D24导出Markdown与完整JSON备份，恢复会先校验格式。浏览器存储只用于课堂接续，长期保存请导出。刷新清除API Key，输入的公开端点与模型名可以随本页练习保存。
