# 第十一周 · 人工智能辅助论文写作

[打开课堂演示](https://lyzhackjp.github.io/pku-aihis/week11/)

本讲共 23 页。先用文献综述矩阵整理研究意见，再用逆向大纲诊断段落，最后核对 Word 修订、脚注和人工智能使用情况说明。课堂中可用顶栏的“文献导入”选取文件，核对题名和页码后，将片段送回课件。公开版含教学练习、修改样稿和文献导入页。

## 本机使用

从仓库根目录运行 `apps/week11/scripts/build_importer.sh` 构建导入页，然后双击 `apps/week11/scripts/start_week11.command`。运行环境与仓库一致，使用 Node 24.19.0 和 pnpm 11.19.0。

在 `apps/week11` 下运行 `pnpm test` 检查教学组件，运行 `pnpm build` 生成公开演示，入口为 `www/pku-aihis/week11/index.html`。
