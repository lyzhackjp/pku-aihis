# 第四周演示与浏览器研究工作台

基于 main 2580682abff19418118e9278781e5997c30f3118 开发。当前按实际处理过程合为8个演示页（W01—W08），同一环节的功能在页内切换；41项原教案对应保留在pages.json，旧P编号链接转到相应环节和功能。待定平台仍不纳入演示。

## 启动与验证

Node 24.19.0、pnpm 11.19.0。在 apps/week04 中执行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm run check
pnpm run build
pnpm preview
```

本机入口 http://127.0.0.1:3334/pku-aihis/week04/；独立工作台追加 ?workbench=1。公开默认示例只有题录，正文与个人研究草稿不在 Git 或正常构建中。教师本机示例用 node scripts/preview.mjs --local-bundle /path/to/bundle 装载；bundle 内含 project.json 和限定附件 ID 的 manifest.json，服务不开放整个文件目录。

本机可选 Zotero Reader 使用 --zotero-reader /path/to/zotero-reader/build/web。完整固定版本源代码、许可证和构建记录须保留在该检出中。未配置比较构建仍可运行核心工作台。它以同源 iframe 嵌入；不能直接把桌面 Zotero 或不同域的阅读器强行装入此接口。

## 已实现

材料身份与版本关系、附件与定位、分类与标签、条件阅读队列、阅读任务与明确输入范围、模型待核候选、人工来源笔记、摘录与释义区分、笔记拆分与上下文、有类型的内部链接和反链、问题索引及支持/反例矩阵、转引依赖组、规范化检索副本、单位粒度、改动失效提示、完整 ZIP 恢复和按编号追加、Obsidian 兼容 Markdown 笔记库导出、只读 Zotero Web API 题录接续。

关键词回找是本轮实际检索方式，未冒称语义向量检索。模型阅读在使用者明确发起请求后发送选中片段；key 只在窗口内存，快照保留输入文字、编号、修订、模型与时间。接口错误明确显示，不保存伪造结果。模型原始输出另存 generatedText，人工核验可另建来源笔记。

源记录、处理片段、个人笔记和论证关系是独立对象。普通检索排除派生文本，原文变动使依赖记录待复核，备份对附件做指纹校验。浏览器数据库支持同一项目在窗口间更新及多个项目切换；它不提供多人协作或自动云备份。

## 按处理过程组织页面

项目与材料身份、材料归组与回找范围、阅读队列与接续、阅读助手与核验、笔记与链接、问题与依据、整理与修订、软件连接与保存，共8页。等价操作直接合并，例如原P14/P15/P16共用一个任务、选文、输入预览与产物界面；P10/P11/P18共用队列详情与暂停接续操作。

项目起步中登记身份只切换本页功能；加入队列直接建立任务。查看其他环节的原件、笔记或保存工具时打开临时面板，关闭后返回原操作。底部前后翻页和课程地图才切换处理环节。浏览器返回键可返回此前环节，页内功能替换当前地址，不制造几十条翻页记录。临时回看不改地址，支持逐层返回和Escape关闭。

材料选择、编辑和结果按内容使用不等宽工作区；原文比较与证据表格另有宽度安排，重复出处移入可展开区，不再把每页机械四等分。工具实例保持挂载，使阅读任务类型、尚未发送的产物等页内状态不因临时回看而销毁。教师窗口同步8个环节及当前功能，合并知识点的教案备注保持可查。

详细合并表见[过程设计](../../docs/week04/process-design.md)。

## 与助教代码和旧 skill 的区别

继承第三周 PR #6 的“问题—操作—结果—依据”对应和同一项目记录，并按第四周实际使用调整布局及粒度。桌面课堂模式限定屏幕高度，工作区可独立滚动；工作台与窄屏按内容展开。源页可放大。

沿用 Stencil deck-slide、课件地图、输入法与可编辑控件翻页保护、独立教师窗口。旧 skill 的单文件 section.slide 模板和初始化脚手架不覆盖现有工程。第四周频道、页面标识与状态独立，未修改第二、三周组件。

## 边界

通用导入器在另一分支，通过精确 origin 与已打开窗口身份交换项目；也可手工上传 ZIP，核心工作台不依赖另一分支才能构建。Zotero 请求仅查询 25 条题录，不取得整库全文，不修改远端库。AnythingLLM 未装载用户实例；Obsidian 本体没有嵌入浏览器，Markdown 以真实独立文件与可解析链接导出。

全站发布白名单暂未加入第四周，不将合并视为上线。独立 CI 检查测试和构建应用。实际合并及验证状态见PR和docs/week04/process-design.md。

[公开题录预览](../../docs/week04/preview.png)只载入公开题录，不含私人原件和研究笔记。

阅读助手可切换“跨材料选择片段”完成明确范围的比较。笔记库导出保留输入快照、模型原始输出与多来源链接；人工改写不覆盖母候选。
